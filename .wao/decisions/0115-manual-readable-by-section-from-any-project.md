# 0115 使用手册在任何项目里按节可读：wao manual，页首 read_when 是“何时读”的唯一来源，不物理拆页

- 日期：2026-11-06
- 状态：accepted
- 来源：Owner 2026-11-05："使用手册可否按场景拆分成基本使用手册（场景放在页首 frontmatter），在 SKILL.md 中被分别指针引用"；2026-11-06 同意本决定的替代做法（按节读取、不物理拆页）。Lead 使用评审 consult_202611051157533033tik52 的 P8；方案会审 consult_20261106143728122oxshpm（kimi、sol）；只读调研 run_20261106140756623sv7qh9。
- 关系：0110（只改文档不跑全量）；SKILL.md 的重排随后另批进行。

## 背景

1. 宿主项目里的 Lead 打不开手册：SKILL 与运行时提示写的是 `docs/usage/delivery.md` 这类相对路径，在宿主项目的工作目录下不存在。按会话统计，两个宿主项目的 Lead 用 Read 工具读手册页的次数是 0。
2. 页级“何时读”写了两份：地图表一列，每页开头一句复述。
3. 大页 37–39KB，读者一次只需要其中一节；手册有约 45 处两边都是正文的重复，字节帽只剩百余字节。
4. 物理拆页要改大量按页路径读手册的测试、写死“某页某节”的运行时文本，以及 ADR 与文档里“场景 4b”这类锚点，收益主要是文件变小。

## 决定

1. **`wao manual`**：从 WAO 安装根（按代码位置推导，不看 cwd）读手册。`wao manual` 列出各页与何时读；`wao manual <页>` 列出该页的节与字节数；`wao manual <页> <节>` 打印一节（二级节含其下三级节），并写明源文件绝对路径；`wao manual <页> --all` 打印整页。节名去掉 Markdown 标记后匹配：标题完全相同者优先，否则按子串，唯一命中才输出，多个命中列出候选、零命中报错，两者都以非零退出；代码围栏里的行不算标题。
2. **页首 frontmatter 的 `read_when` 是“何时读”的唯一来源**：只认 `---` / `read_when: 一行` / `---` 这一种形状。地图表由 `npm run gen:surface` 从它生成，`wao manual` 也读它；每页开头的复述删去，只留回指地图的链接。
3. **手册指针用 `wao manual <页> <节>`**：运行时文本、SKILL 里指向手册的地方都写成这个形状，并由同一个解析器在测试里校验“存在且唯一”。节名改动会在测试里暴露。
4. **不物理拆页**：场景就是节。某个场景按节读出后仍需反复翻读前文时，再单独评估拆那一页。
5. **一件事只写一处**：手册里与架构文档、生成层、其他手册页重复的正文逐条定归属（Lead 的操作做法在手册，机制与合同在架构文档，生成层已承载的参数在生成层），另一处换成指针；字节帽只降不升（第 79 批去重净减约 0.6%，帽维持原值）。工具参数的区间与缺省生成层不写，留在手册。

## 已知边界

- 需要 shell。没有 shell 的宿主（只有 MCP）不在覆盖内；有实证需求时优先考虑 MCP resource，不加工具。
- 没有全局 `wao` 的安装，在安装根下用 `npm run cli -- manual …`，或用安装根里 `scripts/wao-cli.cmd` 的绝对路径。
- 用文件读取工具直接读页时仍是整页。
