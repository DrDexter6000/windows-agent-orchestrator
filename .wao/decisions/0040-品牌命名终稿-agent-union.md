# 0040: 品牌命名终稿——Agent Union（含术语包与占坑）
status: accepted
date: 2026-10-02

## Context

0039 冻结命名待 Owner 新构想。Owner 提出"合作社/生产队"集体主义方向（明确接受争议性："争议=注意力/传播力"+叛逆心），经两轮跨族系会审（GPT/Kimi/DeepSeek 各一席 + Lead=GLM 族；runIds：round3 …747yvmfnx/…897geklwa/…8875tvfz，round4 …306s4fipq/…213jd8rd9/…333duoynr）收敛后 Owner 终审通过。会审核心论证：合作社内核四承重点（①成员自带生产资料入社=worker 各带订阅 ②分工且分强=队长/队员 ③按劳记工分=transcript/token 台账 ④议事定夺=会审）；**Union 是唯一"认知度顶格（程序员一词三梗：C union/SQL UNION/TS union type）+中①③④+与中文术语包同字根可逐词对照（union dues≈工分簿、punch in≈上工、strike fund≈秋收分红）"的常见词**；Soviet 本义=council 只中④——"它翻译的是'会审'不是'合作社'"，且对东欧开发者是未愈合政治伤口（"梗点≠可商用"）。

## Decision

1. **英文子品牌：Agent Union**（全称 WAO Agent Union；描述性副标题 "the agent co-op"）。
2. **中文别名：合作社**（正式对照"智能体合作社"）+ **生产队**（社群梗层自称：队长=Lead、队员=worker）。
3. **术语包（中文 feature 昵称层，Owner 2026-10-02 批准）**：工分簿=transcript/JSONL 台账、上工/收工=派发/完成、记工分=token 计量、社员大会=会审。双语对照可逐词翻译（Union 同字根）。弃用：交公粮（网络俚语雷区）、公社（真实政治引信）。
4. **v1.0 版本代号：Soviet**（反差萌彩蛋位，"In Soviet WAO, agent dispatches YOU"经 Owner 钦点收录）；原候选 Fellowship 弃用。Soviet 仅作代号/彩蛋，永不作正式名。
5. **碰撞披露（知情选择，auditor 异议在案）**：同域同词组碰撞全部规避（agent-coop/agent-guild/Agent Commune/Agent Guild）；"Agent Union" 词组本身无在营产品占位（仅一篇思想实验文章 moltbook.com "The Case for Agent Unions"——梗已预装未占名）；**相邻域占用已披露：Union.ai（MLOps 编排平台）**——裁决依据：union 为通用词（商标弱）、领域可区分、使用全称 WAO Agent Union。auditor 的"任何同名即否决"标准未采纳，其替代提案（WAO Commons/WAO Collective）未获选；本条为由 Owner 知情选择的残余风险。
6. **名称占坑（Owner 2026-10-02 指令）**：`DrDexter6000/agent-union` 公开占位仓库已创建（2026-10-02T10:21:48Z，占位 README 明示 name-reservation、勿 fork、指回主仓）——为将来项目迁移预留。
7. tagline 与 README 主名不变（WAO 保留；"旗舰智力，平价劳力，常设会审 / Rent judgment, buy labor, seat the council"）；Agent Union 是 consult/council 子系统（M13）的品牌名，待 M13 落地时进入产品面。
