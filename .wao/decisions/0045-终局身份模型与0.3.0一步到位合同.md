## Decision（待 Owner 签署后生效）

### 1. 终局实体模型

**1.1 车道 Lane**
- **身份 = 内容指纹**：四元组 `{backend, model.id, model.providerID, providerKey}`
  ——即认证门 `matchedCertRecord`（src/runManager.js:307-316）已在比对的集合。
  改名不失证据；四元组变 = 新身份，不继承旧证明。
- laneId = 人读定位名（标签，非身份）。禁止 laneId 成为新的神圣字符串。
- effort = 车道默认参数（非身份）；认证记录写明"参考 effort"。
- 车道注册表：git 跟踪数据文件，schema 级禁密钥字段（apiKey 值/env 块；
  apiKeyEnv 变量名可入）；私有接线层（agents.json 重键，仍永不入库）通过稳定
  引用绑定车道指纹——两个文件单独改任何一个都无法把 key 导向新端点。
- 唯一组合认证对象；组件层分台账（backend/llm）保留，其 worker 键随本合同同步
  换为车道键。
- 认证用**参考角色**：冻结 sha 的专用角色文件，不随业务角色文件漂移。

**1.2 角色 Role**
- 身份+工作纪律 prompt，库化（config/roles/）。**零整套认证**（口径见 §2）。
- **权限姿态类别由角色声明、车道能力把关**（派发时对不上即拒绝）；
  **会话复用策略由角色声明**；**对抗性从审者车道×作者车道关系派生**
  （取代人工 seatRole 声明）。
- 角色文件首行 = 固定格式用途句（elevator pitch）；wao://roles 展示从它派生，
  禁止第二份手抄。
- 校验：fail-closed 格式校验保留（roleContract.js 现有六项）+ 库成员判定
  （拒绝路径穿越/绝对路径/自由文本）+ 中立性 lint（禁 agentId/身份声明/WAO
  落盘命令/车道模型名；先修 config/roles/auditor.md:3 现存违例）。

**1.3 运行 Run 与事件信封**
- transcript SSOT 不变（不变量 1）。
- run.started 钉：`{车道指纹, laneId, roleId, 角色正文 sha256, 有效配置版本}`。
- 事件信封身份 = laneId+roleId；身份头（worker 被告知的身份）由 lane+role 生成。
- resume/continue/correct 从钉住值重建；指纹不符 fail-closed 零 respawn；旧正文
  不可得时明确拒绝续接（不承诺必然可恢复）。
- 遗留 run（升级日前派发）五态闭集：新钉 / 遗留映射派生 / 映射缺项（具名
  fail-closed）/ run.started 损坏（零 respawn 现路径）/ 角色文件被改（sha 不符
  拒绝）。跨版本 lineage 的 continue/resume 一律固定文案拒绝，不经映射。

**1.4 派发与别名合同**
- 派发 = lane+role 显式组合；CLI/MCP/workflow/会审共用同一解析器（ADR-0017）。
- agentId 入参改 optional，与 lane/role 二选一校验（wire 兼容：第三方现存集成
  靠 agentId，保留不删）。
- **别名合同四条**：只在派发边界解析；解析结果进 run.started；别名本身仅
  informational 字段；禁止别名→别名链。别名表与历史 legacy 名单是两张分离的表。
- 错误消息三原则：说收到了什么 / 列合法全集 / 给可复制修正例（修
  registry.js:190 现存 "Unknown agent" 裸报）。CLI `--explain` dry-run；
  MCP 用 run_dispatch_contract_check 扩展回显 resolved 值（零新工具）。

**1.5 历史身份（自描述派生，非映射考古）**
- 历史 lane 身份从记录自带事实派生（run.started 的 backend/providerKey/model），
  **不从当前注册表**回填。
- 冻结 legacy 席位名闭集（git 跟踪，仅显示用；损坏退回 unknown，可见可接受）。
- 历史角色如实显示"未记录"（转录没记角色，回填=伪造史实）。
- 身份投影三态：normal / legacy 派生 / unknown。

**1.6 会话键（双键位同批升维）**
- 两个键位同一批升级：sessionReuse 问答键 + run_continue 谱系键。
- 键材料 = `leadSession + workspace + 车道指纹 + 角色正文 sha256`（用指纹与
  正文哈希，不用 laneId/roleId 名字——防改名与防改文）。fail-closed 校验严格度
  照搬 canonicalReuseInput（闭集校验，自由文本永不进哈希材料）。
- 升级日：排干 SOP（冻结派发→在途终态→迁移）为主，路由双读兜底为安全网；
  同车道换角色=新会话（有意设计，防串话，写文档防误报）。

**1.7 暴露面**
- 车道/角色 id 与闭集事实**留在工具路径**（扩展 registry_list / lead_preflight）；
  resources（wao://lanes、wao://roles）只放长文案——playbook 先例不可照搬
  （派发必需信息不得只放 resources：第三方宿主不保证呈现 resources）。
- owner-dashboard 改车道视图（44 处 agentId 引用；Owner 话术第一窗口）；
  CLI `wao lanes`（委托同一 service）。
- SKILL.md 12,000B 冻结上限（TD-166）为硬约束，超限须 Owner 重批。
- 字节三步：先按实测重冻（实测 83,099B，10-03 瘦身后静默松弛 1,395B）→
  增量逐包报实测数 → Owner 本轮授权（"改扩展就扩展"）按在册机制逐次记录。
  输出 schema（4 工具 26,481B=32%）本版不动。

**1.8 特性 Traits（首版静态）**
- 车道档案含 Owner 撰写文案（固定来源标签渲染）；观察日志工具化延后 0.3.1
  （runId 证据、可回查/已归档/缺失三态、反证同样可见）。
- advisory 永不门禁：census 守卫钉死特性字段不得出现在 dispatch/gate 文件。

### 2. 认证语义（收窄口径）

- 车道认证证明：**机械路径（运输/证据/隔离/交付）在参考角色、参考 effort 下
  验证过**。角色内容不在认证面；历史角色任务通过 ≠ 对新角色胜任。
- 换角色不触发整套收费认证；角色适合与否由 Lead 判断（不变量 4/6 不动）。
- ADR-0029 承重义务保留（切换当刻 smoke、承重前 delta、换 backend/升主力全量）；
  MCP 默认派发不变成认证门禁（现行 advisory 语义不变）。
- 台账换键（agentId→车道指纹）迁移合同见 §4；manualOverride 不迁移，Owner
  重新签发；0036/0037/0041 例外按"车道×用途边界"重签为 git 跟踪记录、范围取
  最严、原始红项保留。

### 4. 迁移合同

1. **第 0 步清账批**（零行为变化，可直接合 main）：字节按实测重冻；台账清理
   并快照（4/7 席 draft-only 等裁定、3 条陈旧记录、2 条缺 providerKey）；
   gitignored 裁定脚本（adjudicate-0036-0037.mjs）入库或消除；钉 harness 版本
   （TD-210 治理）；修 auditor.md:3；冻结案卷清单（runs 数以清账时点为准）；
   现行为黄金对照测试。
2. **台账迁移**：幂等可重入；迁移证据包入库（迁移前台账 sha256 + 逐条判定 +
   未迁移清单）；前后 case 集合 hash 守恒 + 三键集一致（registry lanes ×
   summary.workers × matrix 行）；迁移期 pruneStaleCases 冻结；R23-C
   missing/null/value 区分保留，缺失不补证、不刷新时间、不自动升 full。
3. **例外重签**：0036/0037/0041 按车道身份重签（git 跟踪），发版门前完成，
   不再依赖 gitignored 手术脚本。
4. **回滚窗口**：真正的不可逆点只有两个——第一次 0.3.0 派发（新形态转录落
   盘）、迁移后第一次台账写入。之前的回滚=逐字节还原；之后只能向前修。
5. **写入器退役**：一次性迁移写入器在切换与回退窗口关闭后退役；legacy 读取
   名单随历史证据长存。

### 5. 发布矩阵与 0038 门"通过"定义（Owner 预裁项，签署即生效）

- 输出 schema 去重（26KB，破坏性变更另议）；特性观察日志工具化（0.3.1）；

### 9. 风险登记（Top 3 + 对冲）

1. **脏台账上换键、例外扩散** → 清账批先行；例外按车道×用途重签取最严；
   manualOverride 不迁；迁移从记录自带事实派生，dry-run 差异呈 Owner。
2. **身份切换 + wire 破坏性变更 + 旧文档/提示词同时失效** → 读取侧先行；
   拒绝文案自带指路；旧 SKILL 会话在新代码全链路绿（别名层验收）；回滚演练。
3. **自由组合后的姿态与独立性塌陷** → 姿态由角色声明+车道把关，派发对不上
   即拒；非作者判定按车道指纹；同源如实显示。
