# 0039: 会审产品化（run_consult）立项与设计契约 v0.2
status: accepted
date: 2026-10-02

## Context

README 双卖点（Rent judgment, buy labor / A council beats a genius）上线（204f9ff/b72a4ae）后，四席红队（auditor run_20261002091004743hm5ppq、coder_mm run_20261002091001505c1xzhf、researcher run_20261002091001351ptr63v、coder_low_dsh run_20261002091439567hyxl6a）确认：会审/council 是操作模式不是产品原语——Lead 每次咨询手搓五步（写共享任务书→拼席位尾巴→逐席派发→抠日志→人工对比），本工作流已手搓 5 次；摩擦本身在惩罚使用会审纪律（0023）。Owner 2026-10-02 批准立项，架构草案 v0.1 经 auditor 判 FAIL-WITH-CHANGES，必改项全部吸收为设计契约 v0.2（本文件）；coder_mm 以四次受试者身份贡献顺从性事实。

## Decision

1. **立项**：`run_consult`（MCP）/ `wao consult`（CLI）进入 roadmap（M13，规划中未开工）。目的：把"召集多席只读咨询"从 Lead 手艺产品化为一个动作——机械扇出+收集+并列呈现，**不做语义合成**（ADR-0018 边界不变）。
2. **设计契约 v0.2**（实现须逐条遵守，红绿测试覆盖）：
   - **输入**：brief 文件（编号问题 Q1..Qn + 输出格式契约）+ 席位清单 + 可选 per-seat 视角片段 + 可选字数上限。视角片段是"答题姿势"（2-3 句：差异化资产 + 自测问题），**禁止**列期望结论关键词/限定候选方向（防独立意见变 Lead 草稿回声）；通用视角可做模板素材（playbook 式），当次语境永远 Lead 手写。
   - **扇出**：并行后台只读 run（自动注入各席凭证/视角）；附"三块砖"独立性事实（厂族不同/非被审作者/不同 provider 会话——全部查表）advisory 提示，黄牌不拦截。
   - **收集**：状态枚举 = 正常/超时/缺席/malformed/部分成功；**运行状态与格式状态分离**（completed+未结构化合法）；malformed 不惩罚——标"未结构化"整段原文呈现，无自动重发，Lead 可选手动重问；席位主动追加的"题外但更重要"不属 malformed；半结构化（某问藏在散文）**不做句子级切分**（切错比不切更糟），按整段原文兜底。
   - **呈现 council-diff**：默认按问题原序；闭集字段值不同仅标"字段值不同"（字面等值比较），**置顶是 Lead 的选项而非自动行为**；同值不折叠理由；工具永不出"一致/分歧"结论；极端格式（长散文对纯 JSON）退回按席全文视图，分页带总量+连续游标+全文入口。
   - **三条不变式（进机器守卫钉住）**：① 对既有脱敏后记录无损——只分组、不摘要、不截断、不排序隐藏（与 ADR-0018 脱敏边界兼容）；② 标记即提示——闭集不同值仅标注，无结论权；③ malformed 零自动重发。
   - **边界（auditor 最大风险项：召集成功≠验收成功）**：子席复用普通只读 run；组层持久记录席位-runId 映射（同时作为意见-决策回链的轻量实现：收集结果附 runId 清单，供 decisions/declare 引用）；不新增 delivery 事件或运行终态；防 metrics 聚合重复计数；永不写认证台账。
   - **修订 0023**：0023 的"不自动派发副审/不新增持久子系统/工具面不动"由本决定显式修订——仅放开"**Lead 显式召集**"一个口子；MCP 工具面新增走既有 wire 冻结面变更流程（m12-10 字节 SSOT + refreeze）。
3. **撤销项（Owner 2026-10-02 裁定）**：内部 A/B 增益实验不做（日常会审带来的方案优化、审计打回的交付物即为实际效果证明，在案可查）；咨询成本账本不立项（nice-to-have；token 总量 runs metrics 已有，将来角色切分若顺手可做，困难永不做）。
4. **品牌线**：tagline 定稿并上线（"Rent judgment, buy labor, seat the council / 旗舰智力，平价劳力，常设会审"，b72a4ae）；README 口号 "A council beats a genius — and costs less than one" 保留（Owner 裁定，正文已有归因引用+限定句）。**子品牌命名冻结**（Owner 2026-10-02：待更大构想）——第一/二轮全部候选与四族会审记录在 .dev/ 任务书及 runs/ transcript 归档（runIds 见 Context），解冻时直接取用；v1.0 代号候选 Fellowship 随命名解冻一并定。

## Consequences

- M13 开工时按本契约实现，三条不变式以红绿测试钉住后才算交付；本契约与 0023 的冲突以本决定为准（0023 保留原文，由本条修订）。
- 咨询仍可继续手搓（本决定不改变现状操作）；consult 原语落地后手搓路径保留为 fallback。
- deepseek-acp 相对 cwd 拒绝（TD-198）等派发面毛刺在 M13 实现时一并审视。
